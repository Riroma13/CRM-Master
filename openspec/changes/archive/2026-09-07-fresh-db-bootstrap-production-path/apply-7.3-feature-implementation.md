## Deviations from Design

- **Bounded mechanical command correction:** the installed Prisma 6 CLI does
  not accept the Design's illustrative `--to-schema` option. The equivalent
  supported `--to-schema-datamodel prisma/schema.prisma` option was used. The
  source schema, `--from-empty`, script mode, generated bytes, and scope are
  unchanged.

No other deviations. No migration history, baseline, `db push`, compensating
migration, existing-database resolve path, API/frontend/auth code, or SDD
runtime/tooling was changed.
